# ItemRack TBC Anniversary - Release v4.39.9

This release improves the options panel layout stability by introducing native screen clamping, ensuring the main options frame and script editor snap back within visible screen boundaries when scaled up.

---

### 🐛 Bug Fixes & Improvements
* **Options Screen Clamping**: Enabled screen clamping for the main options frame (`ItemRackOptFrame`) and the event script editor (`ItemRackFloatingEditor`), preventing them from clipping off-screen when the frame scale is increased.

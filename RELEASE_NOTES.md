# ItemRack TBC Anniversary - Release v4.42

This release updates Classic Era TOC support for version 1.15.9 (build 68808) while maintaining full support for TBC Anniversary 2.5.5 and 2.5.6.

---

### 🚀 Features & Improvements
* **Classic Era 1.15.9 Support**: Updated interface version from `11508` to `11509` in TOC files (`ItemRack.toc` and `ItemRackOptions.toc`) for Classic Era 1.15.9 (build 68808) compatibility, while retaining support for TBC Anniversary 2.5.5 and 2.5.6.
